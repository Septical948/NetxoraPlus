# DBACHECK 2 Alpha 4.3
Adds read-only Backup & SQL Agent Jobs Analyzer.
- Backup inventory: last FULL/DIFF/LOG, recovery model, last FULL size, history.
- SQL Agent jobs: enabled state, last outcome/run/duration/message, history including steps.
- Diagnosis and Evidence Snapshot are read-only.
- No backup, restore, job start/stop or configuration change is executed.
