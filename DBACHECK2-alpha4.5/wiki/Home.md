# DBACHECK 2 Wiki

DBACHECK 2 transforma el assessment batch original en una herramienta interactiva para diagnóstico y resolución operativa de incidentes SQL Server.

## Principios
1. Diagnóstico rápido primero.
2. Evidencia mínima antes de una acción de impacto.
3. Acciones destructivas nunca automáticas.
4. Verificación posterior a la corrección.
5. Modo simple para junior y detalle técnico para DBA experto.
6. El assessment histórico seguirá disponible como función separada.
